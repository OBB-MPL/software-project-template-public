# Changelog

Relevante Änderungen für Nutzer und Betreiber; keine vollständige Commit-Liste. Neue Einträge stehen unter `Unreleased`. Bei einem Release werden sie unter Version und Veröffentlichungsdatum (`YYYY-MM-DD`) zusammengefasst.

Verwendete Kategorien nach Bedarf: `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`. Leere Kategorien weglassen. Versionskonvention: `MAJOR.MINOR.PATCH`; Git-Tags: `vMAJOR.MINOR.PATCH`.
