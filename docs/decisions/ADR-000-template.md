# ADR-XXX: Kurzer Entscheidungstitel

- Status: Proposed
- Datum: YYYY-MM-DD
- Verantwortlich: Name oder Rolle
- Bezug: Issue / Pull Request

## Kontext

Welches Problem muss gelöst werden? Welche Anforderungen und Einschränkungen sind relevant?

## Entscheidung

Was wird konkret entschieden und warum passt es zu den Anforderungen?

## Alternativen

Welche realistischen Optionen wurden geprüft, einschließlich Beibehaltung des bisherigen Zustands? Warum wurden sie verworfen?

## Konsequenzen

Welche Vorteile, Nachteile, Risiken, Kosten und betrieblichen Auswirkungen entstehen? Offene Folgearbeit als Issues verlinken.

## Überprüfung

Unter welchen Bedingungen sollte die Entscheidung neu bewertet werden? Bei Ablösung auf das neue ADR verweisen.
