# Benutzerhandbuch

Diese Vorlage enthält noch keine Anwendung. Im neuen Projekt hier die tatsächliche Nutzung beschreiben:

1. Voraussetzungen und unterstützte Plattformen.
2. Installation und gegebenenfalls benötigte Berechtigungen.
3. Erster Start und ein vollständiges Beispiel.
4. Häufige Arbeitsabläufe.
5. Aktualisierung, Datensicherung und gegebenenfalls Deinstallation.
6. Bekannte Einschränkungen, häufige Fehler und Diagnose.

Anleitungen aus Nutzersicht schreiben und mit der angegebenen Produktversion prüfen. Offene Fehler und Funktionswünsche gehören in GitHub Issues; Sicherheitsmeldungen folgen [SECURITY.md](../../SECURITY.md).
